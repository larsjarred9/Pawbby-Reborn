The Story

Rescuing hardware from cloud abandonment.

When the official Pawbby cloud was discontinued, expensive smart litter boxes were turned into high-tech paperweights overnight. Here is how the community rescued them.

1. The Cloud Shutdown

Without warning, the original Pawbby cloud servers went dark. The vendor mobile app stopped connecting, leaving pet parents unable to configure settings, review cat bathroom history, or control the box remotely.

2. The "No Tuya UI" Dilemma

Under the hood, the litter box communicates using the Tuya protocol. However, unlike standard smart home gadgets, it was manufactured without any standard Tuya control panel UI. Pairing it in the Smart Life app yielded an empty screen with zero controls.

3. Community Reverse Engineering

Rather than letting perfectly good machinery go to the dump, a collective of reverse engineers and cat owners joined forces on Discord. We packet-sniffed raw network communications, decoded every device command, and built our own UI.

4. Pawbby Reborn (AGPL-3.0)

Pawbby Reborn was built to be 100% local, self-hosted, and protected under the GNU AGPL-3.0 license. This guarantees that our community's work remains free, open-source, and immune to corporate takeover or future shutdowns.

Quick Start

Install in minutes.

Choose the installation method that fits your home server or Raspberry Pi.

Deploy with Docker Compose

The cleanest setup for Synology NAS, Unraid, TrueNAS, or any Docker-enabled server.

docker-compose.yml 
services:
  pawbby-reborn:
    image: ghcr.io/larsjarred9/pawbby-reborn:latest
    container_name: pawbby-reborn
    ports:
      - "3333:3333"
    volumes:
      - pawbby_data:/app/data
    restart: unless-stopped

volumes:
  pawbby_data:
1

Save the snippet above as docker-compose.yml in your preferred directory.

2

Run the container in background mode:

Terminal 
docker compose up -d
3

Open http://<your-server-ip>:3333 in your web browser to start the onboarding wizard!

Tip: To update later, simply run docker compose pull && docker compose up -d.

Home Assistant Add-on

Natively integrated into your Home Assistant sidebar with seamless ingress support.

1

Navigate to Settings → Add-ons → Add-on Store in your Home Assistant instance.

2

Click the 3 dots in the top right, select Repositories, and add our community repository:

Repository URL 
https://github.com/larsjarred9/Pawbby-Reborn
3

Find Pawbby Reborn in the store, click Install, and turn on Show in sidebar.

PM2 / Bare Metal (Raspberry Pi)

Lightweight deployment with full support for the built-in 1-Click Update UI feature.

Terminal 
# 1. Clone repository
git clone https://github.com/larsjarred9/Pawbby-Reborn.git
cd Pawbby-Reborn

# 2. Install dependencies & build
npm install
npm run setup

# 3. Start background process with PM2
pm2 start ecosystem.config.cjs
pm2 save
pm2 startup
1-Click Updates: When a new update is released, a notification banner appears in your dashboard. Simply click "Update Now" to run upgrade.sh automatically!
